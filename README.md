# מחולל פעולות דביר קדוש | שבט מעוז

גרסה 2 של מחולל פעולות צופים חכם.

## מה שונה בגרסה הזו

- מפתח OpenAI נשאר בשרת ולא בדפדפן.
- העלאת PDF, Word או TXT מתבצעת דרך השרת.
- המתודות מוגבלות לרשימה קבועה.
- השרת בודק את התוצאה אחרי שהמודל מחזיר אותה.
- סכום הזמנים חייב להיות בדיוק הזמן שביקשת.
- כל חלק חייב לכלול מתודה וזמן.
- המבנה מוחזר כ-JSON לפי Schema קשיח.
- הקובץ שהועלה ל-OpenAI נמחק לאחר עיבוד.
- יש הגבלת קצב בסיסית לבקשות.
- יש ייצוא PDF ו-Word.
- הממשק מותאם לנייד.

## הפעלה

דרוש Node.js בגרסה עדכנית.

1. פתח טרמינל בתוך התיקייה.
2. הרץ:

```bash
npm install
```

3. העתק:

```text
.env.example
```

לקובץ:

```text
.env
```

4. פתח את `.env` והכנס:

```text
OPENAI_API_KEY=המפתח_שלך
OPENAI_MODEL=gpt-5.6-luna
PORT=3000
```

5. הרץ:

```bash
npm start
```

6. פתח:

```text
http://localhost:3000
```

## מצב פיתוח

אפשר להריץ:

```bash
npm run dev
```

## אבטחה

אל תעלה את `.env` ל-GitHub.

בשרת ציבורי כדאי להוסיף משתמשים, התחברות, שמירת פעולות במסד נתונים, הגבלת מכסה לפי משתמש וניטור עלויות.
